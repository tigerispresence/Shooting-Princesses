- **잠들 때 연출** OMG 진짜 웃길 것 같아!! 베개가 떨어진다고? YES 최고
- **도구들** 분필 던지기, 알람시계, 손전등... 이렇게 자기만의 무기가 있는 게 최고야
- **캐릭터 커스터마이징** 머리색이랑 옷색을 내가 고르는 거?? 그리고 이름도?? YES YES YES 이건 꼭 해야 해
- **숨기 메커닉** 사물함에 숨었다가 나올 타이밍을 내가 정한다? 그거 긴장된다
- **급식표 모으기** 10개를 다 모으면 내가 고른 메뉴가 급식 나온다고?? 미쳤다. 이 때문에 자꾸 다시 할 듯

## 이상한/답답한 것들
- **친구 구출이 손해처럼 느껴질 것 같은데?** +800점은 좋지만 감지 +20%는 진짜 불리하게 느껴질 수 있어. 아 이건 정말 하기 싫을 수도
- **스테이지 1이 너무 쉬운가?** 문서 읽어보니 진짜 질 수 없다고 했는데, 그럼 긴장이 없어서 재미가 없을 수도. 좀비 한 마리는 빠르게 해야 할 것 같은데
- **어두운 방이 짜증날 수도** (스테이지 3) 화면 못 보는 게 답답한데, 손전등 켜면 들킨다는 게... 왜 굳이 못 보게 했어? 하지만 이건 그냥 어려운 거니까 도전한다는 마음으로 하면 될 것 같기도

## 무섭거나 안 좋은 것
- **없어!!** 졸음 좀비는 귀엽고 완전 무섭지 않음 ✓
- 게임오버도 죽는 게 아니라 같이 자는 거라니 이게 왜 떠올렸는지 모르겠지만 완벽함
- 색깔도 파스텔이고 다 뭉글뭉글하니까 안 무서워

## 개방형 질문 답변 (DESIGN.md 섹션 10)

1. **스테이지 1이 너무 쉬운가?** → 쉬운 게 맞는 것 같아. 처음 게임을 배우는 거니까. 근데 1-3에서 좀비 한 마리를 빠르게 해 주면 "아 이건 도망만으로 안 되네" 하면서 사물함을 써 볼 이유가 생길 것 같음
2. **0.6초 유예 시간** → 그 정도면 괜찮을 것 같아. 너무 짧으면 억울하고 길면 게임이 쉬워지니까 딱 좋을 것 같은데?
3. **분필 무한** → 무한이 맞아. 자꾸 막힐 거 같으면 짜증난다. 쿨다운이 있으니까 막으로는 못 써
4. **손전등 감지 ×1.35** → 처음엔 못 알아챠겠지만, 맨 처음 손전등 켤 때 선생님이 "불빛 때문에 일어나!" 라고 말해 주면 알아챌 것 같아
5. **친구 구출 +20% 페널티** → 이건... +10%로 낮추거나 구해야 깨울 수 있다는 시간만 비용이면 좋을 것 같아. 지금이면 "아 구하지 말까" 할 듯
6. **교장 보스 사이클 16.7초** → 어... 조금 길 수도? 12초가 더 나을 것 같은데?
7. **세로 화면 타일 12×16** → 괜찮을 것 같은데, 넓은 스테이지에서 화면이 너무 좁으면 갑자기 튀어나오는 좀비 때문에 깜짝 놀라겠지 (이건 스트레스). 줌아웃 옵션 있으면 좋을 것 같아
8. **가로 모드** → 아니 세로만 해. 게임은 세로로 하는 게 맞아
9. **오늘의 급식 데일리 챌린지** → **이건 무조건 해야 해!!** 내일도 켤 이유가 생긴다
10. **급식표 10개** → 딱 좋은 것 같은데? 스테이지마다 2개면 한 판에 두 개니까 리듬도 좋고, 10개 다 모으는 데 시간도 적당함
