# 플레이 리뷰 — 「학교 좀비, 살아남자!」(10살 관점)

## 1. 첫인상 — 제목·이름·의상 화면

네, 당연히 시작하고 싶어요! 제목도 재미있고 (학교 좀비 🧟 살아남자!), 의상 커스터마이징이 정말 좋아요. 머리색이 4개, 옷색도 8개나 되고 다 예쁜 색이예요. 아무것도 못생기거나 헷갈리지 않고, 아기 같지도 않아요. 버튼들도 크고 누르기 쉬워요.

## 2. 게임플레이 — 무엇을 해야 하는지 한눈에 보임

설명 없이도 완벽히 알겠어요. 좀비 = 귀여운 파란 사물함 + 눈, 친구 = 다른 캐릭터 + 파란 빛, 아이템 = 색깔있는 작은 사각형. 절대 무섭지 않음. 어두운 방도 예쁜 보라색이라 겁내지 않아요. 손전등 메커닉이 쿨해요 — 더 잘 보이지만 더 잘 들키는 trade-off!

## 3. 잠든 게임오버 화면 — 웃겨요!

"꿈에서 급식을 세 번이나 더 먹었다" 😂 "베개 대신 급식판을 베고 잤다" 터졌어요! "10초 잤는데 100년 잔 기분" — 이건 반칙이죠. 종 버튼("종 치고 다시!")도 마음에 듭니다.

## 4. 게임 안 대사들

- 친구 구출: "나여기! 하린아, 나 좀 데려가 줘!" → 너무 귀여움
- 교장 연설: "어디까지 얘기했더라?" → 지루한 게 포인트라니까 천재! 웃겨요
- 어떤 대사도 길거나 cringe하지 않음. 뮤트해도 화살표·불빛·게이지로 다 알 수 있어서 좋아요

## 5. 제 이전 우려사항들 — 다 해결됨

- ~~친구 구출하면 감지 +20%~~? → 완전 삭제됨 ✓ 감사해요!
- 스테이지 1이 너무 쉬움? → 배고픈 좀비 1마리 추가됨 ✓
- 교장이 너무 길어? → 사이클 12.2초로 단축 ✓
- 친구 4명은 어디 갔어? → 스테이지 4에 다 배치 ✓

## 6. Top 3 바꾸고 싶은 것 & 자랑하고 싶은 것

**바꾸고 싶은 것:**
1. 좀비들이 모두 똑같이 생김. 반응할 때 표정 변하거나 다른 모양이 되면 더 좋을 것 같아요
2. 사물함에 숨기 전에 안에 뭐가 있는지 볼 수 있으면 좋겠어요
3. 엔딩에 구출한 친구 4명이 모두 보였으면 좋겠어요

**자랑하고 싶은 것:**
어두운 방의 손전등 메커닉! 무섭지 않으면서도 스릴 있고, risk(더 들킴) vs reward(더 잘 봄)의 밸런스가 완벽해요!

## 7. 최종 점수

**9/10** — 내일도 꼭 다시 할 거예요! 메커닉도 명확하고, 대사도 재미있고, 미술도 귀여워서 친구 4명도 다 구출하고 싶고 스테이지도 다 깨고 싶어요. 10이 아닌 이유는 좀비가 좀 더 다양하면 더 완벽할 것 같아서예요.
