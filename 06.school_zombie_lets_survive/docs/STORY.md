# 학교 좀비, 살아남자! — 스토리 라인 (초안 v0.1)

Among Us 느낌의 탑다운 2D. 배경은 초등학교. 좀비를 피해 방마다 아이템을 모아 학교를 구한다.
싱글 플레이. 주인공 이름은 플레이어가 정한다. 게임오버는 코믹하게.

## 한 줄 컨셉
급식 신메뉴 "보라 브로콜리 푸딩"을 먹은 전교생이 하품하는 **졸음 좀비**가 됐다.
푸딩을 안 먹은 주인공이 학교 곳곳에서 "잠 깨우기 재료"를 모아 해독제를 만들고, 방송실에서 기상 나팔을 틀어 모두를 깨운다.

## 왜 좀비인가 (무섭지 않게)
- 급식실 신메뉴 "보라 브로콜리 푸딩" → 먹은 사람은 5교시에 하품 → 눈이 보라색 → 느릿느릿 걸으며 "숙제… 숙제…" 중얼거리는 졸음 좀비
- 좀비는 나쁘지 않다. 그냥 너무 졸려서 아무나 껴안고 같이 자고 싶어 한다
- 좀비에게 잡히면 → 나도 졸려서 눈이 감김 (게임 오버). 피 없음, 물림 없음
- 해독제 원리: "시끄럽고, 맵고, 상쾌한 것" = 잠 깨는 것들

## 등장인물
- **주인공** (플레이어, 4학년): 브로콜리를 싫어해서 푸딩을 안 먹음. 시작 화면에서 이름을 직접 입력 (한글 최대 6자, 추천 이름 버튼 몇 개 제공, localStorage에 기억). 모든 대사에 이름이 들어간다: "{이름}아, 과학실 쪽지 찾았니?"
- **보건 선생님** (조력자): 다이어트 중이라 푸딩을 안 먹음. 무전기로 힌트를 준다. "과학실 쪽지 찾았니?"
- **과학 동아리 쪽지**: 해독제 레시피. 재료 8개(스테이지마다 2개)를 모아 과학실로
- **졸음 좀비 학생·선생님**: 느리다. 하품 소리로 위치를 알 수 있다
- **급식 아주머니 좀비**: 국자를 들고 급식실 순찰. 조금 빠르다
- **교장 선생님 좀비** (최종 보스): 엄청 느리지만 "아침 조회 연설"을 시작하면 주변이 다 졸린다 (범위 공격). 연설 중엔 눈을 감고 있어서 지나갈 수 있다

## 스테이지 흐름 (5스테이지)
| 스테이지 | 장소 | 모을 재료 | 새로 나오는 것 |
|---|---|---|---|
| 1. 점심시간 끝 | 1층: 급식실, 보건실, 현관 | 보건실 비타민, 급식실 매운 고추장 | 기본 좀비, 사물함에 숨기 |
| 2. 5교시 | 2층: 4학년 교실들, 복도 | 알람시계, 분필 (던지면 좀비가 딴 데 봄) | 급식 아주머니 좀비, 문 잠그기 |
| 3. 특별실 | 3층: 음악실, 미술실, 도서관 | 음악실 큰북, 도서관 "잠 깨는 무서운 책"(사실 웃긴 책) | 어두운 방 (손전등), 여러 마리 동시에 |
| 4. 체육관·운동장 | 넓은 야외 | 체육관 응원 나팔, 운동장 차가운 물호스 | 넓은 곳에서 좀비 떼 피하기, 친구 구출 |
| 5. 과학실 → 방송실 | 옥상층 | 재료 합쳐 해독제 완성 → 방송실까지 배달 | 교장 선생님 좀비 보스, 방송실 문 앞 대결 |

## 스테이지 안의 기본 루프
1. 방에 들어가 아이템 위치를 지도에서 확인
2. 좀비 순찰 피하며 아이템 획득 (짧은 미니 동작: 서랍 열기, 자물쇠 번호 등)
3. 잡힐 것 같으면 사물함/청소도구함에 숨기, 또는 분필·알람시계로 주의 돌리기
4. 재료를 다 모으면 출구 열림 → 다음 층

## 사이드 목표
- **친구 구출**: 아직 안 졸린 친구가 교실에 숨어 있다. 구하면 따라다니며 아이템 하나를 대신 들어 준다
- **급식표 수집**: 방마다 숨겨진 급식표 조각. 다 모으면 엔딩에서 새 메뉴 공개

## 엔딩
방송실에서 "기상 나팔 + 해독제 안개" 방송 → 전교생이 기지개 켜며 깨어남.
교장 선생님: "보라 브로콜리 푸딩은 오늘부로 금지!"
급식 아주머니: "그럼 내일은 딸기 푸딩으로 할게요."
주인공은 전교 조회에서 "학교를 구한 영웅" 상장을 받는다. 마지막 컷: 다들 웃으며 딸기 푸딩 먹기.
(급식표를 다 모았다면: 주인공이 좋아하는 메뉴가 급식표에 올라간다)

## 확정 사항
- 싱글 플레이
- 주인공 이름은 시작 화면에서 입력. 외모(머리색·옷색) 선택 2~4종
- 게임오버는 코믹하게 (아래)

## 게임오버 연출 (코믹)
좀비에게 잡히면 죽는 게 아니라 **같이 잠든다**.

기본 연출 (약 3초):
1. 주인공이 큰 하품 → 눈이 스르르 감김. 주변 좀비들도 따라 하품
2. 하늘에서 베개가 툭 떨어지고, 다 같이 바닥에 쓰러져 "zzz" 말풍선. 화면이 살짝 어두워지며 코 고는 소리
3. "딩동댕동" 쉬는 시간 종소리 → 주인공만 벌떡 일어남 "아 깜짝이야! 얼마나 잤지?"
4. 버튼: **「종 치고 다시!」** (같은 스테이지 재시작)

잡은 상대에 따른 변주:
- 급식 아주머니: 국자로 푸딩을 한 입 떠먹여 준다 → 주인공 "맛있…" 하고 잠듦
- 교장 선생님: 연설이 너무 길어서 잠듦. 화면에 "…그리고 세 번째로…" 자막
- 친구 좀비: 껴안고 같이 코~ 잠. 하트 대신 zzz 하트

잠들 때마다 랜덤 한 줄 (엔딩에서 "몇 번 잤는지" 카운트로 웃김 포인트):
- "5교시에 자면 안 되는데…"
- "꿈에서 급식을 세 번이나 더 먹었다"
- "잠꼬대: 숙제… 다 했어요…"
- "베개가 생각보다 푹신했다"
