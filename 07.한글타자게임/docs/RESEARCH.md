# 리서치: 한메타자교사 / 한컴타자연습

## 원작 구성 (한메타자교사, 한메소프트 1989~)
- 연습 메뉴: **자리연습**(글쇠 익힘) → **낱말연습** → **단문(짧은 글)** → **장문(긴 글)** → 통계 → 타자 게임
- 두벌식/세벌식 지원 (우리는 **두벌식 표준만**)
- 대표 게임 **베네치아(산성비)**: 하늘에서 단어가 떨어진다. 바닥(벽돌/물)에 닿기 전에 타이핑하면 사라짐. 놓치면 벽돌이 녹아 도시가 잠긴다. 7개 난이도, 단계마다 유명 건축물 배경.
  - **노란 단어**: 놓쳐도 피해 없음. 치면 랜덤 효과 — 화면 전체 지우기, 느리게/빠르게, 얼리기, 벽돌 수리, (벌칙) 단어 숨기기·속도 증가.
- 한컴타자연습: 자리연습 단계가 「기본자리 → 윗글쇠 → 아랫글쇠 → 가운데(ㅗ ㅓ ㅏ ㅣ / ㅠ ㅜ ㅡ) → 쌍자음 → 전체」 식으로 확장. 게임은 두더지 잡기(자리연습 8단계 기반, 50단계), 판 뒤집기, 동전쌓기 등.
- 타수: 한국식 "타" = 자모 키 입력 수 기준 분당 타수(CPM). 정확도 % 함께 표시.

## 두벌식 표준 자판 (event.code → 자모)
```
Q ㅂ  W ㅈ  E ㄷ  R ㄱ  T ㅅ  Y ㅛ  U ㅕ  I ㅑ  O ㅐ  P ㅔ
A ㅁ  S ㄴ  D ㅇ  F ㄹ  G ㅎ  H ㅗ  J ㅓ  K ㅏ  L ㅣ
Z ㅋ  X ㅌ  C ㅊ  V ㅍ  B ㅠ  N ㅜ  M ㅡ
Shift: Q ㅃ W ㅉ E ㄸ R ㄲ T ㅆ O ㅒ P ㅖ
```
- 기본자리(홈 포지션): 왼손 ㅁㄴㅇㄹ(A S D F), 오른손 ㅓㅏㅣ(J K L) + 검지 ㅎ/ㅗ(G/H). F, J 돌기.
- 손가락: 왼새끼 QAZ, 왼약지 WSX, 왼중지 EDC, 왼검지 RFV TGB, 오른검지 YHN UJM, 오른중지 I K, 오른약지 O L, 오른새끼 P.

## 핵심 기술 결정 (중요)
**OS 한글 입력기(IME)에 의존하지 않는다.** 브라우저 IME는 composition 이벤트가 브라우저·OS마다 다르고, 아이가 한/영 전환을 잘못하면 아무것도 안 된다.
→ `keydown`의 `event.code`(물리 키)를 위 표로 자모로 바꾸고, **게임 안에 두벌식 오토마타(초성/중성/종성 조합, 겹받침·겹모음, 종성 이동 "갃+ㅏ")**를 직접 구현한다. 한/영 상태와 무관하게 항상 한글이 나온다. 화면 키보드에 다음 칠 키를 하이라이트할 수 있고, 키 단위로 정확도를 잴 수 있다.
- 판정: 목표 단어를 자모 시퀀스로 분해해 두고, 키 하나하나를 다음 기대 자모와 비교 → 틀린 키는 즉시 표시(빨강), 진행은 맞은 키만. (Backspace도 지원)
- 유니코드 조합: 0xAC00 + (초성*21 + 중성)*28 + 종성.

## 대상/제약
- 10살 여자아이 둘, **데스크톱 전용(모바일 미지원)**, 키보드 필수. 터치 컨트롤 불필요.
- 콘텐츠: 무섭지 않게. 산성비 → 귀엽게 바꿀 것 (예: 비구름 대신 별/사탕/꽃잎, 도시 대신 마을/성).
- 단어는 저작권 없는 일반 낱말 + 직접 쓴 짧은 문장. 아이 눈높이 어휘.
